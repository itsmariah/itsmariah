## 🖥️ Projetos

### ⭐ SkillUp Dev
> Plataforma web gamificada voltada ao aprimoramento de soft skills para desenvolvedores, com desafios interativos e feedback automatizado com apoio de IA.

`HTML` `CSS` `JavaScript` `Node.js`

[![Repositório](https://img.shields.io/badge/Repositório-black?style=for-the-badge&logo=github)](https://github.com/itsmariah/skillupdev) [![Deploy](https://img.shields.io/badge/Ver%20projeto-6B57FF?style=for-the-badge&logo=render&logoColor=white)](https://skillupdev.onrender.com)



### ⭐ GeldTrack <sub>(antigo MoneyTrack)</sub>
> Plataforma de gestão financeira pessoal e compartilhada: contas, sincronização bancária via Open Finance, relatórios, metas, orçamentos e divisão de despesas em grupo. Funciona na web, como PWA e como app desktop.

`React` `JavaScript` `Node.js` `Express` `PostgreSQL` `Prisma` `Electron` `Vitest`

[![Repositório](https://img.shields.io/badge/Repositório-black?style=for-the-badge&logo=github)](https://github.com/itsmariah/geldtrack) [![Deploy](https://img.shields.io/badge/Ver%20projeto-6B57FF?style=for-the-badge&logo=vercel&logoColor=white)](https://geldtrack.vercel.app)



### 🧁 MistyDoces <sub>(em desenvolvimento)</sub>
> Sistema web completo para uma confeitaria artesanal real: cardápio, pedidos online, pagamento por Pix e cartão via Mercado Pago e painel administrativo com níveis de acesso.

`TypeScript` `Next.js` `React` `Tailwind CSS` `PostgreSQL`

[![Repositório](https://img.shields.io/badge/Repositório-black?style=for-the-badge&logo=github)](https://github.com/itsmariah/mistydoces)



### ✂️ Barbearia Clássica <sub>(projeto em equipe)</sub>

`HTML` `CSS` `JavaScript`
